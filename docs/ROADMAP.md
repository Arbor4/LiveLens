## Phase 1：选区工具栏与可配置 OCR / 大模型管线

### 1.1 选区交互升级（CaptureView）
- 悬停自动吸附软件窗口与顶部菜单栏，单击或拖拽进入**选区锁定态**（不再松手即翻译）。
- 锁定后支持：
  - 8 个控制点微调宽高；
  - 选区内部拖动平移位置；
  - 选区外重新拖拽绘制新区域。
- 选区下方弹出**悬浮工具栏**，提供四个明确入口：
  - **截图翻译**：单次识别并渲染译文；
  - **识别文字**：OCR 提取文本并复制剪贴板；
  - **原位实时**：进入模式 1（Phase 3 接入，Phase 1 先完成接口预留或基础提示）；
  - **副屏实时**：进入模式 2（Phase 2 接入）；
  - **取消 / Esc**：退出选区。

### 1.2 OCR 与翻译引擎解耦
- **图片/屏幕翻译模式切换**（设置页可选）：
  - `OCR + 文本/大模型引擎`（本地化闭环，支持静态与实时）；
  - `有道图片翻译`（保留原有云端整图翻译能力，可随时切回）。
- **OCR 引擎选择**（设置页可选）：
  - `Apple Vision`（macOS 原生 `VNRecognizeTextRequest`，走 ANE，零模型体积）；
  - `RapidOCR`（通过独立 Python 本地 HTTP 服务 `http://127.0.0.1:9003/ocr` 调用，内置连通性测试）。
- **翻译大模型解耦**：
  - 增强 `LlmConfig` / `LlmTranslateClient`：支持本地 OpenAI 兼容端点免填 API Key，新增 `HY-MT1.5-1.8B`（Ollama / llama.cpp / MLX）一键预设及连接测试。
  - 新增行聚类合并（邻近行合并为自然段）+ 背景色/前景色采样 + 批量翻译 + LRU 缓存。
  - 前端按 `OverlayRegion` 归一化/局部坐标渲染结构化译文块（自动自适应字号 + 遮罩底色）。

### 验收标准
- 选区后可自由拖动边角与位置，并弹出悬浮工具栏；
- 设置页可在「Apple Vision / RapidOCR」和「OCR+翻译 / 有道图译」间自由切换；
- 本机无网络/仅开启本地大模型时可完成截图识别与结构化覆盖翻译；
- `npm test` 与 `cargo test` 全部通过并提交阶段 Commit。

## Phase 2：区域持续录屏与模式 2（实时翻译副屏）

### 2.1 区域持续采集与双速异步管线
- macOS 通过原生 `ScreenCaptureKit`（`SCStream` / `SCScreenshotManager`）持续抓取选中区域画面，支持**排除 LiveLens 自身窗口**。
- **高速画面通道**：通过本地轻量二进制 HTTP/流式接口把选区画面推送给副屏播放器（不走 JSON Base64 IPC）。
- **节流 OCR + 翻译通道**：
  - 像素帧差比对，画面静止时不重复 OCR；
  - 变化后触发选定的 OCR（Apple Vision / RapidOCR）；
  - 文本行级哈希去重 + 译文缓存命中，只把新增/变化段落发给 `HY-MT1.5-1.8B`；
  - 通过 Tauri Event 推送最新 `OverlayRegion[]` 至副屏。

### 2.2 模式 2：实时翻译副屏窗口（`mirror.html`）
- 新增独立可拖拽、可缩放、可拖到副屏全屏的播放窗口。
- 底层渲染同步过来的选区录屏画面，上层按等比坐标叠加结构化译文覆层。
- 支持同步模式切换：**「智能关键帧（省电超清）」** 与 **「流畅视频流」**；支持暂停冻结、双语对照/仅译文切换、透明度调节与重选区域。

### 验收标准
- 工具栏点击「副屏实时」后弹出副屏窗口并实时同步选中区域画面与译文；
- 拖动、缩放副屏窗口时译文位置严格等比跟随；
- `npm test` 与 `cargo test` 通过并提交阶段 Commit。

## Phase 3：模式 1（原位置穿透覆盖）与完整交付

### 3.1 模式 1：原位置实时穿透覆盖（`overlay.html`）
- `OverlayView` 升级为结构化实时译文渲染层（支持 **「原位块覆盖」** 与 **「吸底半透明字幕条」** 两种样式）。
- 覆盖窗口精确对齐原选区并开启 `set_ignore_cursor_events(true)` 鼠标穿透，不影响底层网页、视频或游戏操作。
- 采集时通过窗口排除列表过滤 `overlay` 与控制条自身窗口，杜绝自录死循环。
- 提供独立可拖拽的迷你悬浮控制胶囊（暂停/继续、切换模式 1 ↔ 模式 2、切换字幕条样式、重选区域、关闭）。

### 验收标准
- 模式 1 与模式 2 可在运行时一键无缝切换；
- 覆盖层可穿透点击底层窗口且不发生译文自我重录闪烁；
- 全量测试通过，完成 macOS `.dmg` / `.app` 最终构建并提交阶段 Commit。
